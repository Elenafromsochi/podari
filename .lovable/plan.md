# Гид по сервису для новых пользователей

Создаю интерактивный туториал-онбординг, который ведёт нового пользователя через весь сервис шаг за шагом. Прогресс сохраняется — если человек прервался, продолжаем с того же места.

## Что делаю

### 1. Хранилище прогресса
Новый модуль `src/lib/tour-state.ts`:
- Ключ в localStorage: `cozygift_tour_step_v1` — id текущего шага гида
- Ключ `cozygift_tour_done_v1` — флаг завершения
- API: `getTourStep()`, `setTourStep(id)`, `completeTour()`, `isTourActive()`
- Привязка к user_id (чтобы у нескольких аккаунтов на устройстве не путалось)

Старый `WelcomeCoachmarks` (3 шага) убираю — заменяется новым гидом.

### 2. Движок гида
Новый компонент `src/components/tour/TourOverlay.tsx`:
- Полноэкранный затемнённый оверлей с «дыркой» вокруг подсвечиваемого элемента (как сейчас в WelcomeCoachmarks, но мощнее)
- Поддерживает шаги без подсветки (просто карточка по центру)
- Поддерживает шаги с конфетти
- Кнопка-CTA с произвольным текстом, опционально кнопка «Пропустить тур»
- Шаги задаются декларативно: `{ id, target?, title?, text, cta, confetti?, onCta? }`

Новый файл `src/lib/tour-steps.ts` — массив всех шагов с текстами из ТЗ.

Контекст `TourProvider` в `__root.tsx` — чтобы любой экран мог триггерить «следующий шаг» при нужном действии (открыли вкладку «Получить», выбрали подарок, попали в чат и т.д.).

### 3. Точки интеграции (data-tour атрибуты)
Чтобы оверлей знал куда указывать, добавляю `data-tour="…"` на:
- кнопку «Получить подарок» на главной (HomeTab)
- нижняя навигация (BottomNav) — целиком, и отдельно вкладки «Главная», «Профиль», «Чаты»
- блок статистики на главной (показатели сервиса)
- секция «Подарили» в ленте
- секция «Загадали» (желания)
- верхняя плашка с балансом/опытом (AppHeader)
- кнопка «Пригласить друга» в профиле
- нижняя зона профиля (мои подарки/желания)
- кнопка «Написать админу» в чатах

### 4. Сценарий гида (как в ТЗ)
1. **Экран авторизации** — заголовок меняется на «Выбери свой первый подарок», под ним кнопка «Авторизоваться через Telegram».
2. **После входа на главную** — конфетти + модалка «У тебя есть 1 подарочный балл…», кнопка «Как выбрать подарок?»
3. Подсветка кнопки «Получить подарок» + текст «Нажми сюда»
4. После клика — открывается вкладка «Получить», поверх всплывает «На 1 уровне доступны категории Вещи и Услуги и время…»
5. При выборе категории с подкатегориями — «И здесь сделай выбор»
6. При открытии списка подарков — «Ты добрался до настоящих сокровищ, выбирай любое!»
7. После взятия подарка в чат — «Ты попал в чат с Дарителем, 1 балл заморожен», кнопка «Понятно»
8. В чате — «Тут ты можешь выбрать шаблонное сообщение либо отказаться…», «ок, что дальше?»
9. «Пока ждёшь — изучи остальные разделы», «Давай»
10. Подсветка нижней навигации → «Пошли на Главную»
11. На главной — подсветка статистики, «ок»
12. Подсветка «Подарили» → «Далее»
13. Подсветка «Загадали» → «Класс!»
14. Подсветка вкладки «Профиль» → «Пошли дальше!»
15. В профиле — подсветка верхней плашки, серия сообщений про уровень/опыт/баллы (3 шага)
16. Подсветка «Пригласить друга», текст про +50 опыта/+1 балл другу
17. «Пригласи прямо сейчас!» — клик копирует ссылку, конфетти + поздравление
18. Подсветка нижней зоны профиля (мои подарки/желания), «Отлично!»
19. Подсветка вкладки «Чаты» → «Жми!»
20. В чатах — текст про отзывы, «Договорились»
21. Финал — текст про «Написать админу» и установку на рабочий стол, «С удовольствием!» → completeTour()

### 5. Возобновление
- При загрузке приложения (после auth) проверяем `getTourStep()` — если не `done`, рендерим `<TourOverlay startAt={step}/>`.
- Каждый раз когда пользователь совершает «продвигающее» действие (открыл вкладку «Получить», попал в чат и т.д.), вызываем `tour.advanceIfAt('step-id')` — это переключает шаг даже если человек обновил страницу.
- Кнопка «Пропустить тур» помечает гид завершённым.

## Технические детали

- Все тексты CTA и сообщений вынесены в `tour-steps.ts` — легко редактировать.
- Оверлей не блокирует таргет: клик «сквозь дырку» по подсвеченному элементу разрешён (`pointer-events: none` на маске вокруг hole), чтобы пользователь реально нажимал кнопки и продвигался.
- Если шаг ссылается на элемент, которого нет на текущем экране (например, пользователь сам ушёл в другую вкладку), показываем шаг без подсветки + подсказку «Перейди в …».
- Прогресс сохраняется per-user (`cozygift_tour_step_v1::<user_id>`), чтобы при логауте/смене аккаунта не было кросс-загрязнения.
- Кнопка «Пропустить» в каждом шаге, плюс крестик в углу.
