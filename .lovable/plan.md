## 1. Экран входа
- В `AuthFlow` заменить заголовок «Вход в Подари» → «Выбери свой первый подарок».
- Главная кнопка → «Авторизоваться через Телеграм» (Telegram остаётся текущим способом входа).

## 2. Глобальная верхняя плашка (`AppHeader`)
Новый компонент `src/components/AppHeader.tsx`, виден на всех экранах после входа.
Содержимое слева → справа:
- Аватар (инициал) + имя пользователя
- Уровень (Lv N) и прогресс-бар XP
- Баланс подарочных баллов (🎁 N)
- Иконка сообщений с бейджем непрочитанных → клик ведёт на вкладку «Чаты»

Подключаем в `AppShell`, на страницах `chat/$giftId`, `cabinet`, `wish/*` и т.д. (через layout-route `_app` или прямым включением в каждый screen).

## 3. Глобальная нижняя плашка
`BottomNav` уже есть. Добавим его рендер на страницы вне `AppShell` (чат, экраны желаний, кабинет), чтобы он был везде. Активная вкладка определяется по текущему роуту.

## 4. Кнопка «назад»
Везде, где сейчас `onBack` ведёт жёстко на `/cabinet` или `/`, заменить на `router.history.back()` (с фолбэком на `/`).

## 5. Главная страница (`HomeTab`)
Новая структура сверху вниз:
1. Компактная строка статистики: «🎁 X активных · 💝 Y подарено · ⭐ Z желаний исполнено» (обновление раз в час, кэш через серверную функцию).
2. Кнопки «Подарить» и «Получить подарок» (остаются, чуть ниже).
3. Поиск по активным подаркам (только текстовый ввод, голос убираем).
4. **Лента с двумя вкладками** в одном блоке:
   - «Подарки» — активные подарки + завершённые (как сейчас в `DealsFeed`)
   - «Желания» — все открытые желания (из `WishesFeed`)
   Переключение табами внутри одного контейнера, бесконечный скролл.

Серверная функция `getHomeStats` возвращает три числа, кэшируется в памяти на час.

## 6. Поиск
- Убрать голосовой ввод (`Mic`/`SpeechRecognition`) из главной и чатов.
- Поле ищет по `title`/`description`/`category` среди `gifts WHERE status='available'`.

## 7. Переделка чата (`ChatScreen`)
- Шапка: «Даритель: <имя>» + строка с названием/описанием подарка.
- Под шапкой кнопки в зависимости от роли:
  - **Получатель:** красная кнопка «Отказаться от подарка» (вызывает `cancel_claim`).
  - **Даритель:** две кнопки — «Подтвердить получение» (зелёная, `confirm_handover` — но эту функцию сейчас может вызвать только receiver; нужно добавить вариант для sender или переиспользовать `request_handover`) и красная «Отказаться от дарения» (новая функция `cancel_by_sender`).
- Сообщения:
  - свои (отправитель = я) — зелёный фон, белый текст;
  - входящие — белый фон, тёмный текст.
- Кнопка отправки — зелёная.
- Подсказки готовых сообщений над инпутом (видны, пока чат пуст / по запросу):
  - «Мне понравился ваш подарок. Как могу его забрать?»
  - «Расскажите подробнее о вашем подарке, а именно… » (вставляется в поле для дозаполнения).

## 8. БД-изменения
Добавить функцию `cancel_by_sender(_transaction_id uuid)` (sender отменяет сделку: tx → cancelled, gift → available, баланс получателя возвращается). Миграция отдельным шагом до правок кода чата.
