## Фича «Пожелания» (Wishes)

Параллельная сущность к подаркам: человек публикует, что он хочет получить (фото + описание), другие видят это в ленте, могут нажать «Исполнить пожелание» → открывается чат → даритель приносит → пожелатель подтверждает «Получено».

---

### 1. Экономика (баллы и опыт)

**Пожелатель (тот, кто разместил пожелание):**
- Размещение пожелания: **−0.2 балла** + **+10 XP**
- Когда пожелание исполнено (подтвердил «Получено»): **−0.8 балла** (итого −1 балл за исполненное желание) + **+10 XP**

**Даритель (исполнитель пожелания):**
- Нажал «Исполнить пожелание»: **0** (резерв не нужен — он отдаёт, а не получает)
- Пожелание исполнено: **+1 балл** (фикс на старте; коэффициент по «дороговизне» обсудим позже) + **+80 XP**

> Важно: цифра +1 для дарителя — заглушка-константа. Позже добавим множитель (1/2/3) от tier цены подарка, как договорились.

---

### 2. База данных (миграция)

**Новая таблица `wishes`:**
- `id`, `owner_id` (uuid, кто пожелал), `title`, `description`, `image_url`
- `category` (как у gifts), `status` ('open' | 'reserved' | 'fulfilled' | 'cancelled')
- `created_at`, `updated_at`
- RLS: SELECT всем authenticated, INSERT/UPDATE/DELETE — только owner

**Новая таблица `wish_transactions`:**
- `id`, `wish_id`, `wisher_id` (получатель подарка), `giver_id` (исполнитель)
- `status` ('pending' | 'completed' | 'cancelled')
- `handover_requested_at`, `created_at`
- RLS: SELECT — обе стороны

**Расширение `chats`:** добавить `wish_id uuid NULL` — чат может быть либо по gift, либо по wish.

**RPC функции (security definer):**
- `publish_wish(...)` → списывает 0.2, начисляет 10 XP, создаёт wish
- `fulfill_wish(_wish_id)` → проверки, ставит wish.status='reserved', создаёт wish_transaction (pending), открывает чат
- `request_wish_handover(_tx_id)` → даритель сообщает «отдал»
- `confirm_wish_received(_tx_id)` → пожелатель: −0.8 балла, +10 XP; дарителю +1 балл, +80 XP; wish.status='fulfilled'
- `cancel_wish_claim(_tx_id)` → возврат статуса 'open'

### 3. Серверные функции (`src/lib/wishes.functions.ts`)
- `publishWish({ title, description, image_url, category })`
- `listWishes({ category? })` — лента всех открытых пожеланий
- `getWish(id)`
- `fulfillWish({ wish_id })` → возвращает `{ transaction_id, chat_id }`
- `confirmWishReceived({ transaction_id })`
- `requestWishHandover({ transaction_id })`
- `getMyWishes()` — мои размещённые пожелания

### 5. UI: новые экраны

**`WishForm.tsx`** — форма создания пожелания (по образцу `GiveGiftForm`):
- Фото (опционально), название, описание, категория
- Подсказка: «Размещение: −0.2 балла, +10 опыта»
- Кнопка «Загадать желание»

**`WishesFeed.tsx`** — лента пожеланий:
- Карточки: фото, заголовок, имя пожелателя, время, категория
- Фильтры по категории
- Тап → `WishDetails`

**`WishDetails.tsx`** — карточка пожелания:
- Фото, описание, профиль автора (ссылка на `/user/$userId`)
- Кнопка «🎁 Исполнить пожелание» (если не свой и status='open')
- Если своё: «Снять с публикации»

**Новая вкладка в `BottomNav`:** добавить «Желания» (иконка `Sparkles` или `Star`) — или сделать переключатель внутри HomeTab (Подарки / Желания) — **рекомендую переключатель внутри HomeTab**, чтобы не раздувать таб-бар.

### 6. Чат для пожеланий

Расширяем `ChatScreen.tsx`:
- Если `chat.wish_id` есть — показываем шапку «Пожелание: …» вместо «Подарок: …»
- Кнопки:
  - Даритель: «Я принёс / передал» → `requestWishHandover`
  - Пожелатель: «Получено» → `confirmWishReceived`
- После confirm — toast «+10 опыта», у дарителя «+1 балл, +80 опыта»

`ChatsTab.tsx` — в список чатов добавляются и wish-чаты, помечаем иконкой ✨
